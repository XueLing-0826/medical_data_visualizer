# Medical Data Visualizer

A freeCodeCamp data analysis project using medical examination data.

# Features

- Calculates whether patients are overweight using BMI
- Normalizes cholesterol and glucose data
- Visualizes categorical health indicators
- Cleans invalid and extreme records
- Creates a correlation heatmap

# Technologies

- Python 3.10
- Pandas 1.5..3
- Seaborn 0.13.2
- Matplotlib
- NumPy 1.24.4

This is the boilerplate for the Medical Data Visualizer project. Instructions for building your project can be found at https://www.freecodecamp.org/learn/data-analysis-with-python/data-analysis-with-python-projects/medical-data-visualizer
